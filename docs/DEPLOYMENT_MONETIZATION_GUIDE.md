# 🚀 첫 배포 및 수익화 완전 정복 가이드

직접 만든 웹 서비스를 세상에 내놓고 수익까지 창출해보고 싶으신가요? 이 가이드에서는 현재 작성된 코드를 바탕으로 **실제 서버에 배포하는 과정부터 구글 애드센스로 돈을 버는 방법까지** 컴공생 및 초보자 눈높이에 맞춰 단계별로 설명합니다.

---

## 1단계: 배포 인프라 준비하기 (GCP & GitHub)

### 1-1. 클라우드 서버(가상 컴퓨터) 대여하기
우리는 Google Cloud Platform(GCP)의 **Compute Engine(VM)** 을 서버로 사용할 것입니다. 첫 가입 시 주어지는 $300 크레딧이나 무료 티어(e2-micro)를 활용할 수 있습니다.

1. **GCP 콘솔 가입 및 프로젝트 생성:** 구글 클라우드에 가입하고 새 프로젝트를 만듭니다.
2. **Compute Engine 인스턴스 생성:**
   - 머신 타입: `e2-micro` (무료 티어 권장)
   - 운영체제(OS): `Ubuntu 22.04 LTS`
   - 방화벽 설정: **"HTTP 트래픽 허용", "HTTPS 트래픽 허용" 둘 다 체크 필수**
3. **고정 IP 할당 (중요):** 서버 전원이 꺼지더라도 IP가 바뀌지 않도록 VPC 네트워크 설정에서 '고정 외부 IP 주소(Static IP)'를 발급받아 인스턴스에 연결합니다.

### 1-2. 도커와 도커 허브
미리 작성된 `Dockerfile`은 이 서비스를 Nginx 서버로 감싸주는 역할을 합니다.
1. [Docker Hub](https://hub.docker.com/) 에 회원가입을 합니다.
2. 회원가입한 **Username**과 **Password(또는 Access Token)** 을 꼭 기억해 둡니다.

---

## 2단계: 자동 배포 연동하기 (CI/CD)

작성해 둔 `.github/workflows/deploy.yml` 파일 덕분에, 앞으로 터미널에서 `git push origin main`만 입력하면 자동으로 GCP 서버에 배포됩니다. 단, 깃허브가 GCP와 도커 허브에 로그인할 수 있도록 **비밀번호(Secrets)** 를 알려주어야 합니다.

1. 본인의 GitHub Repository 웹페이지에 접속합니다.
2. **Settings(설정) > Secrets and variables > Actions** 로 이동합니다.
3. **New repository secret** 버튼을 눌러 다음 5개의 값을 등록합니다.

| Secret 이름 | 입력할 값 (Value) |
|---|---|
| `DOCKERHUB_USERNAME` | 도커 허브 아이디 |
| `DOCKERHUB_TOKEN` | 도커 허브 비밀번호 (또는 Access Token) |
| `GCP_VM_IP` | GCP에서 발급받은 '고정 외부 IP' 주소 |
| `GCP_VM_USER` | GCP SSH 접속에 사용하는 유저명 (보통 `ubuntu` 또는 본인 구글 아이디) |
| `GCP_SSH_KEY` | GCP 서버에 접속할 수 있는 SSH Private Key 내용 전체 |

> **💡 SSH Key 생성 팁:**
> 로컬 컴퓨터 터미널에서 `ssh-keygen -t rsa -b 4096`을 입력해 키를 생성한 뒤, `.ssh/id_rsa.pub` 내용(퍼블릭 키)은 GCP 서버 리눅스 머신의 `~/.ssh/authorized_keys`에 복사해 넣고, `.ssh/id_rsa` 내용(프라이빗 키)은 GitHub `GCP_SSH_KEY`에 등록하면 됩니다.

## 3단계: 나만의 도메인 구입과 연결

숫자로 된 IP 주소(예: `123.45.67.89`)로는 사람들이 기억하기도 어렵고 애드센스 승인도 불가능합니다.

1. **도메인 구매:** 가비아, 후이즈, 혹은 Namecheap 같은 사이트에서 `.com` 또는 `.kr` 등 원하는 도메인을 하나 구매합니다. (1년 약 1~2만 원 선)
2. **DNS 레코드 연결 (A 레코드):** 구매한 도메인 설정 창에서 `A 레코드` 항목을 찾아, GCP 서버의 **고정 IP 주소**를 입력하고 저장합니다.
3. 이제 인터넷 창에 내 도메인을 치면 배포된 메뉴 추천 서비스가 짠! 하고 나타납니다.

## 4단계: 진짜 목적! 애드센스로 돈 벌기 💸

`index.html` 코드에 이미 애드센스 광고가 들어갈 수 있는 공간(`<ins class="adsbygoogle" ...>`)을 만들어 두었습니다. 이제 구글의 허락만 받으면 됩니다!

### 4-1. 애드센스 가입 및 사이트 등록
1. [Google AdSense](https://adsense.google.com/) 에 접속하여 가입합니다.
2. 메인 화면에서 **[사이트 추가]**를 누르고 조금 전 구매한 **나만의 도메인 주소**를 입력합니다.

### 4-2. 애드센스 소유권 확인 (코드 삽입)
구글이 "이 사이트 진짜 네 거 맞아?" 라고 물어보며 `<script async src="..."></script>` 형태의 코드를 줍니다.
- 걱정 마세요! 이미 `index.html` 의 `<head>` 부분에 해당 형태의 스크립트를 넣어두었습니다. 
- 스크립트의 `client=ca-pub-XXXXXXXXXXXXXXXX` 부분만 **본인의 애드센스 고유 아이디(Publisher ID)**로 수정하고 깃허브에 다시 푸시(`git push`)하세요.

### 4-3. 광고 단위(Ad Slot) 발급 및 적용
1. 애드센스 메뉴에서 **[광고] > [광고 단위 기준] > [디스플레이 광고]**를 만듭니다.
2. 생성 완료 후 발급되는 코드에서 `data-ad-slot="1234567890"` 이라는 10자리 숫자를 찾습니다.
3. `index.html` 코드 상 하단 광고 부분의 `data-ad-slot="XXXXXXXXXX"` 을 방금 복사한 10자리 숫자로 변경합니다.

### 4-4. "애드고시" 통과를 위한 꿀팁 (매우 중요 ⭐)
구글은 아무 사이트나 광고를 주지 않습니다. 콘텐츠가 충분해야 승인을 내줍니다.
- 방금 만든 이 사이트는 기능은 좋지만 '글자 수'가 부족해서 단번에 승인받기 어려울 수 있습니다.
- **해결책:** 도메인 안에 `/blog` 같은 경로를 만들어 **메뉴 리뷰, 맛집 탐방 등 텍스트 기반의 글을 10~15개 이상 꾸준히 업로드** 하거나, 결과 페이지 아래에 메뉴의 영양 성분이나 레시피 텍스트를 풍부하게 추가하는 방식으로 콘텐츠 볼륨을 키우세요.

승인이 완료되면(길면 2~3주 소요) 페이지에 빈칸으로 보였던 자리에 실제 광고가 랜덤으로 송출되며, 사용자들이 메뉴를 추천받고 클릭할 때마다 달러($)가 차곡차곡 쌓이게 됩니다. 건승을 빕니다!
